Закрепление водителей за автомобилями

За автомобилем можно закрепить несколько водителей. Для каждого водителя назначается один автомобиль по умолчанию. При оформлении новой путёвки водитель может выбрать любую другую машину.

Даты зимнего периода могут переходить через Новый год. Изменение настроек влияет на незакрытые расчёты; для эксплуатации потребуется версионирование календаря сезонов и закрытие месяцев.
